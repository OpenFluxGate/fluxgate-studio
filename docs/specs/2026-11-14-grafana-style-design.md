# Studio 콘솔 Grafana 스타일 개편 설계

- 작성일: 2026-11-14
- 상태: 승인
- 선행: `2026-11-14-monitoring-console-design.md` (PR #8). 같은 브랜치 `feature/monitoring-console`에서 이어서 작업한다.

## 1. 목표

모니터링 콘솔의 화면과 조작 방식을 Grafana에 맞춘다. 운영자가 Grafana에서 익힌 습관(시간 범위, 자동 갱신, 변수, 패널 메뉴, 드래그 확대, TV 모드)을 그대로 쓸 수 있게 하는 것이 목표다.

## 2. 범위

포함한다.

1. 다크 기본 테마
2. 상단 시간 범위 선택과 자동 갱신
3. 규칙 묶음 변수
4. uPlot 시계열, 세로선 툴팁, 드래그 확대, 범례 표, 패널 간 커서 동기화
5. 임곗값 색 숫자 패널
6. 패널 메뉴: 크게 보기, 데이터 표 보기, CSV 내려받기
7. 접히는 행
8. TV 모드
9. 접히는 아이콘 사이드바

제외한다.

- 패널 드래그로 배치 바꾸기, 대시보드 저장과 공유 설정
- 서비스 변수. 판정 이력에 서비스를 구분하는 필드가 없다.
- 임곗값 설정 화면. 이번에는 고정값을 쓴다.

## 3. 시간 범위 (admin-api 변경)

### 3.1 요청

모니터링 API 세 개(`overview`, `timeseries`, `top-rejected`)는 두 가지 중 하나로 기간을 받는다.

- 상대 기간: `window=5m|15m|1h|6h|24h`
- 절대 기간: `from`, `to` (epoch ms). 둘 다 있어야 하고, `from < to`, 길이 24시간 이하, `to`는 현재보다 1분 넘게 미래일 수 없다.

둘 다 오면 `from`, `to`를 쓴다. 어긋나면 400(`InvalidRuleException`, 필드 `from` 또는 `window`).

키 조회 기간(`1h`, `24h`, `7d`)은 그대로 둔다.

### 3.2 구간 크기

서버가 기간 길이에 맞춰 고른다. 후보는 10초, 30초, 1분, 5분, 15분이고, 구간 수가 120개를 넘지 않는 가장 작은 값을 쓴다.

| 기간 | 구간 |
|---|---|
| 5분 | 10초 |
| 15분 | 10초 |
| 1시간 | 30초 |
| 6시간 | 5분 |
| 24시간 | 15분 |

### 3.3 캐시

상대 기간은 지금처럼 `window` 코드로 캐시한다. 절대 기간은 `from`, `to`를 구간 크기로 내림한 값을 캐시 키로 쓴다.

### 3.4 응답

`OverviewResponse`, `TimeseriesResponse`의 `window`에는 상대 기간이면 코드를, 절대 기간이면 `"custom"`을 담는다. `from`, `to`, `bucketMillis`는 지금처럼 돌려준다.

### 3.5 구현 단위

- `MonitoringRange`(record): `from`, `to`, `bucketMillis`, `cacheKey`, `label`. 정적 팩토리 `of(String window, Long from, Long to, long now)`가 검증과 구간 선택을 맡는다.
- `MonitoringWindow`는 키 조회 전용으로 남긴다(`KEY_LOOKUP`). 모니터링 쪽 사용처는 `MonitoringRange`로 바꾼다.
- `MonitoringService`의 세 메서드는 `MonitoringRange`를 받는다.

## 4. 화면 (UI)

### 4.1 테마

- 다크가 기본이다. 저장된 선택이 없으면 `data-theme="dark"`로 시작한다. 선택지는 다크, 라이트, 시스템.
- 다크 색은 Grafana에 맞춘다. 페이지 `#111217`, 패널 `#181b1f`, 선 `#2a2d33`, 글자 `#d8d9da`, 보조 글자 `#8e9196`.
- 계열 색: 허용 파랑(다크 `#3987e5`, 라이트 `#2a78d6`), 차단 빨강 `#d03b3b`. 두 모드 모두 색약 검증(`validate_palette.js`)을 통과했다. 적록 조합은 쓰지 않는다.
- 상태 색: 정상 `#0ca30c`, 주의 `#fab219`, 위험 `#d03b3b`. 상태 색은 항상 아이콘과 함께 쓴다.

### 4.2 틀

- 아이콘 사이드바: 기본 너비 48px, 아이콘과 마우스 올림 툴팁. 펼치면 180px에 메뉴 이름. 펼침 상태는 `localStorage`에 둔다(읽기 실패해도 기본값으로 동작).
- 상단 바: 위치 표시, 시간 범위 선택, 축소 버튼, 새로고침, 자동 갱신 간격(끄기, 10s, 30s, 1m), TV 모드 버튼. 개요 외 화면에는 시간 범위와 자동 갱신이 없다.
- TV 모드: 사이드바와 상단 바를 숨기고 패널만 보인다. 주소의 `kiosk` 파라미터로 켜고, Esc나 화면 오른쪽 위 버튼으로 끈다.

### 4.3 주소 상태

개요 화면의 상태는 주소에 둔다. 새로고침이나 링크 공유에도 그대로 열린다.

| 파라미터 | 값 | 기본 |
|---|---|---|
| `from`, `to` | `now-1h`처럼 상대값, 또는 epoch ms | `now-1h`, `now` |
| `refresh` | `off`, `10s`, `30s`, `1m` | `10s` |
| `ruleSet` | 규칙 묶음 ID | 없음(전체) |
| `kiosk` | 있으면 켜짐 | 없음 |

상대값 `now-5m`, `now-15m`, `now-1h`, `now-6h`, `now-24h`는 API의 `window`로 바꿔 보낸다. 절대값이면 `from`, `to`를 보내고 자동 갱신은 멈춘다.

### 4.4 개요 패널

행 세 개, 각 행은 접을 수 있고 접힘 상태는 `localStorage`에 둔다.

1. 요약 행: 숫자 패널 4개.
   - 판정, 차단, 차단율: 시계열 응답의 구간 합계로 계산하고, 배경에 구간별 미니 추이를 그린다. 변수를 고르면 그 묶음 값이다.
   - 차단율 임곗값: 1% 미만 정상, 5% 미만 주의, 그 이상 위험.
   - 활성 규칙: `/api/dashboard/stats`.
2. 추이 행: 시계열 패널(넓게)과 많이 차단된 키 패널(좁게).
   - 시계열: uPlot. 허용은 파랑 선과 옅은 영역, 차단은 빨강 선과 옅은 영역. 세로선과 툴팁, 아래에 평균, 최대, 마지막 범례 표. 드래그하면 그 구간이 절대 시간 범위가 된다.
   - 많이 차단된 키: 표, 차단 수 칸에 막대 게이지.
3. 규칙 묶음 행: 묶음별 표. 미니 추이, 판정, 차단, 차단율(막대 게이지와 임곗값 아이콘), 마지막 판정. 행을 누르면 변수가 그 묶음으로 바뀐다.

### 4.5 패널 메뉴

모든 패널 제목 오른쪽에 메뉴를 둔다.

- 크게 보기: 패널 하나를 화면 전체로 보여 준다. Esc로 닫는다.
- 데이터 보기: 패널 데이터를 표로 보여 준다. 차트의 대체 화면이기도 하다.
- CSV 내려받기: 데이터 보기와 같은 표를 CSV로 내려받는다.

### 4.6 나머지 화면

- 규칙: 지금 기능 그대로, 표를 패널 모양으로 바꾼다.
- 키 조회: Grafana Explore처럼 위에 조회줄, 아래에 상태 패널, 시계열(uPlot), 최근 판정 표.
- 변경 기록: 로그 목록 모양. 시각, 사용자, 동작, 대상, 내용을 한 줄로 두고, 누르면 펼쳐서 상세를 보인다.

## 5. 의존성

- `uplot` 1.6.32 (MIT, 의존성 없음). 브라우저에서만 쓰므로 컴포넌트 안에서 마운트 후 생성한다.
- 이전 설계의 "차트 라이브러리를 추가하지 않는다"는 이 문서로 바꾼다. 미니 추이와 막대 게이지는 지금처럼 직접 그린다.

## 6. 오류 처리

- 절대 기간이 잘못되면 API가 400을 돌려주고, 화면은 기본 기간으로 되돌린 뒤 알림을 보인다.
- 시계열 조회가 실패하면 마지막 데이터를 유지하고 상단에 갱신 실패를 표시한다(지금과 같다).
- `localStorage`를 읽거나 쓰지 못해도 화면은 기본값으로 동작한다.

## 7. 테스트

- admin-api: `MonitoringRange` 검증(상대, 절대, 둘 다, 길이 초과, 미래, 순서 뒤바뀜), 구간 선택 표, 캐시 키 내림. 컨트롤러는 `from`, `to` 전달과 400.
- UI, Vitest 순수 함수:
  - 주소 상태 파싱과 직렬화(`now-1h`, 절대값, 잘못된 값)
  - 상대값과 API 파라미터 변환
  - 축소 계산(기간 두 배, 현재 시각을 넘지 않음)
  - 숫자 패널 집계와 임곗값 판정
  - 범례 통계(평균, 최대, 마지막)
  - CSV 변환(쉼표, 따옴표, 줄바꿈 처리)
- 실행 확인: 데모 데이터로 개요를 열어 드래그 확대, 축소, 변수 선택, 자동 갱신 끄기, TV 모드, 패널 메뉴 세 가지, 행 접기, 사이드바 펼치기를 브라우저로 확인한다.
